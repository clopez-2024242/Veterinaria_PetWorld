# Veterinaria_PetWorld
Sistema de Gestión para Veterinaria (JavaFX)
Desarrollé una aplicación de escritorio para la administración de una clínica veterinaria utilizando JavaFX y MySQL. El sistema permite gestionar clientes, empleados, veterinarios, proveedores y vacunas desde una interfaz gráfica intuitiva. Este proyecto me permitió fortalecer mis conocimientos en arquitectura MVC, conexión a bases de datos mediante JDBC, desarrollo de interfaces con JavaFX y organización de aplicaciones orientadas a objetos.
